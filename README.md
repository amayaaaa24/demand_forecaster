## Project Overview

This project builds a machine-learning workflow to forecast order quantity for an online sporting-goods wholesale and retail dataset. The goal is to support inventory planning by predicting future demand based on product category, price information, and time-based features.

The project includes exploratory data analysis, feature engineering, model comparison, business value estimation, and a deployed Flask web application for generating predictions.

## Business Problem

Accurate demand forecasting is important for retail and wholesale operations. Poor forecasts can lead to overstocking, stockouts, delayed fulfillment, and unnecessary business costs.

In this project, I compared several regression models to determine whether machine learning could improve order forecasting compared with a Linear Regression benchmark.
